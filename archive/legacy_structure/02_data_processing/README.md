# 02 数据处理

状态：`archived`（历史流程）。

入口：`02_数据处理.ipynb`

本阶段位于数据分析和模型训练之间，一次性产出可直接训练的数据：

- Train、Valid、Test 边界；
- 训练、验证和测试掩码；
- 稳定数值特征选择；
- 逐时间截面排名；
- `mask_x` / `mask_y` 覆盖核对与模型需要的样本口径；
- 只使用过去信息的历史缺口趋势补值；
- 1、5、20、60 期滞后、差分和历史可用性特征；
- 基于 Train 分位数的异常值诊断和可选截尾；
- 面向线性回归的稀疏 One-Hot / 频率编码，以及面向树模型的整数编码。

正式产出位于 `processed_data_v1/`：

- Tree：419列，Train、Valid、Test；
- Linear：479列，Train、Valid、Test；
- Sequence：`(3603, 5282, 40)`及独立掩码；
- Common：统一标签、时间、股票和分组索引；
- `manifest.json`和`READY`验收标记。

当前实际大小约34.8 GiB。模型训练只有在`READY`存在且manifest哈希一致时才允许开始。
Notebook独立读取`data.z`，构建完成后自动清理临时解压与历史缓存，不依赖`03_模型训练`。
