# 附件3模板视觉与结构提炼

- 源文件：`Document/附件3-项目实现方案模板.docx`
- 页面：A4 纵向，单栏，页眉为赛事名称与下划线，页脚为居中页码。
- 封面：大面积留白；居中大标题；下方项目名称、团队名称横线；底部保留填写说明框。
- 第 2 页：目录，六章结构固定。
- 第 3–8 页：每章新页；章标题黑色粗体，正文小四仿宋、1.5 倍行距；模板提示文字为蓝色。
- 正文结构：项目介绍（含项目概况）、项目实施方案、项目创新性分析、项目实现成果、项目合规风险分析、参考文献。
- 约束：项目概况建议不超过 1500 字，实施方案建议不超过 2000 字；不得出现参赛队员或指导老师姓名；同时提交 DOCX 与 PDF。

创建策略：复制模板，保持节、页眉、页脚、页码、标题样式与分页属性，仅替换封面字段和六章占位文字。未完成的正式训练结果明确标注“待用户运行后回填”。
