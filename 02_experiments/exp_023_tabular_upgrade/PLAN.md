## 1. 发现链（5 个只读探针，全部结论可复现）

1. **cat_5 = 股票 ID**（stock→cat_5 近似完美双射，仅 1 值冲突）
2. **个股长期均值 alpha 不存在**：train 期个股均值 → valid IC = -0.0048（近期窗口同样为负）
3. **y 有极强短期自相关**：y(t-1)→y(t) 截面 IC = 0.777（正率 100%），但 lag≥5 衰减到 ≈0，
   纯持久性递归 243 步 mean IC ≈ 0 → 递归路线不可行
4. **X 列 417/418 相同且无信号**（IC 0.019），排除
5. **决定性发现：未来截面特征对当前 y 有强预测力**——X(t+5) 的 num_348 对 y(t) 单特征 IC 0.46；
   y 的窗口中心在 t+5 附近；特征里没有 y(t-1) 的强代理（最强 0.147）

机制：y(t) 的标签窗口覆盖 t 之后的多个截面，X(t+s) 的特征天然包含 y(t) 窗口内的价格信息。
⚠️ **历史探针假设已被推翻**：虽然比赛一次性发放全部 test 特征，但主办方强因果规则禁止用 `X(t+s)`（`s>0`）预测 `y(t)`。该路线仅作为机制验证保留，状态为 `causal_status=invalid`，不得用于晋级或正式提交。

## 2. 方法（run_exp023a.py，18 分钟全流程）

- **scan**：train 尾段 180 截面 × 408 特征 × shifts{0,1..6,8,10,12,15} 扫描 (feat,shift) 截面 IC
  （选择与评估分离：train 侧选，valid 侧评估）
- **eval**：top-N 等权 rank 平均（负 IC 取反 rank），未来截面借 test X（与推理信息集一致）；
  N∈{32,64,128,256} 扫描，shift0 保底 0.125 权重防尾部截面退化
- **submit**：最优 N 对 442 个 test 截面推理（尾部缺 shift 的截面跳过缺失组合）→ 组内 rank → 网格
