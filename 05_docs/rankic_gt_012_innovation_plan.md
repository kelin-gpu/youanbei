# RankIC > 0.12 创新实验方案

状态：`target_achieved_and_formally_promoted_online_0.120847`

日期：`2026-08-23`
目标：在严格因果合规、保留 exp023h 基线的前提下，使线上 RankIC 超过 `0.12`。

## 1. 结论

首选方向不是重做大模型，也不是再训练一个自由路由器，而是：

> **状态检索驱动的局部 Rank 残差手术**
>
> State-Retrieved Rank Residual Surgery，简称 SRRRS。

它只在历史上存在可靠相似状态、且 OOF 证据表明校正收益为正的 Test 截面上，修正 exp023h 的截面内排序；其余截面逐值保留 exp023h。

核心由三个可分离、按顺序验收的变量组成：

1. 用当前截面的无标签市场状态检索历史相似截面；
2. 在检索样本上学习 exp021 的截面排序残差；
3. 仅在高置信截面启用修正，并可选地将训练目标替换成可微 Spearman。

任何一步失败就停止，不把多个未经验证的机制一次性混合。

## 2. 为什么选择这个方向

### 2.1 项目证据

- 合规线上最佳 exp023h 为 `0.119660`，距目标仅 `0.000340`。
- exp023h 相对 exp021 只实质修改了前 6 个截面；大部分 Test 仍是 exp021 原样输出。
- exp020/021 的成功改动很小；exp016-pruned、exp019、exp023g 则再次证明普通栈侧 `+0.001x` 本地增益不可靠。
- exp023e/f/h 连续三次线上正向，说明“默认保留强基线、只改有机制证据的小区域”比全局替换稳健。
- exp021 全量 Valid 中，高漂移 20% 截面比其余截面低 `0.003316`，存在可利用但不适合全局重构的状态差异。
- 现有 head 的目标是 Pearson 相关、pairwise、tail、confidence 和 residual 的组合，并未直接优化 Spearman RankIC。

### 2.2 论文启发与项目化改造

- [RAFT](https://arxiv.org/abs/2505.04163) 从训练集检索与输入相似的历史模式，并利用这些模式补充预测模型。这里不检索未来信息，只检索 `s < t` 的历史截面。
- [MetaDA](https://arxiv.org/abs/2401.03865) 在股票非平稳场景中，同时利用新出现和历史复现的模式。这里采用其“任务级状态匹配”思想，但不引入完整元学习系统。
- [MASTER](https://arxiv.org/abs/2312.15235) 指出特征有效性会随市场状态变化。这里仅用轻量、可审计的市场状态向量做检索，不再增加深层 Transformer。
- [Fast Differentiable Sorting and Ranking](https://proceedings.mlr.press/v119/blondel20a.html) 给出了 `O(n log n)` 的可微 rank，可直接构造 Spearman 损失。这里仅用于小型残差校准器，不替换整个专家栈。
- [Invariant Risk Minimization Games](https://proceedings.mlr.press/v119/ahuja20a.html) 支持跨环境稳定性约束；但 IRM 也存在脆弱性，因此本项目只采用多时间环境一致性和最差环境门槛，不直接训练完整 IRM。
- [TAFAS](https://arxiv.org/abs/2501.04970) 等测试时适应方法依赖部分已观测真实标签；本赛题除起始锚点外没有同等反馈，所以不把在线参数更新列为主方向。

本方案和既有失败路线的本质区别：检索改变的是**训练样本的局部相关性**，不是根据当前状态自由混合七个专家；最终输出又受 exp023h 强收缩和截面级开关约束。

## 3. 突破目标的定量分解

`0.12 - 0.119660 = 0.000340`。RankIC 是 442 个 Test 截面的均值，因此需要新增的截面 IC 总量为：

```text
442 × 0.000340 = 0.150280
```

在不动 exp023h 前 6 个锚点截面的前提下，可在其余 436 个截面中择优修改。例如：

| 修改截面数 | 占剩余截面 | 每个被修改截面的平均净增益要求 |
|---:|---:|---:|
| 44 | 10.1% | 0.003416 |
| 87 | 20.0% | 0.001727 |
| 109 | 25.0% | 0.001379 |

因此不需要产生一个全局大幅领先的新模型；需要的是一个能可靠识别约 10%–25% 有利截面的校正器。

## 4. 严格信息边界

预测截面 `t` 时只允许：

- `X(<=t)`；
- `s<t` 的 Train/Valid 真实标签；
- `s<t` 的自有预测；
- 仅在历史训练段拟合的 scaler、PCA、距离尺度和校准参数。

禁止：

- 用 `X(t+k), k>0` 构造状态或近邻；
- 用当前/未来标签选择近邻、门控阈值、混合权重；
- 在完整 Valid 上训练门控后再汇报同一 Valid 的收益；
- 根据 Test 全期统计量反向标准化较早 Test 截面。

Test 可逐截面向前执行；每个状态向量只能由当时已经可见的数据生成。

## 5. 状态向量与检索

对每个时间截面构造 `z_t`，只包含无标签、低维、稳健的统计量：

1. `drift_feature_registry.csv` 中 `stable_keep` 和 `rank_or_robust_transform` 特征的截面中位数、MAD、10/90 分位数和缺失率；
2. 主要类别的截面占比与集中度；
3. exp021 六个基础家族预测的截面分散度、两两一致性和 head confidence；
4. 当前相对历史滚动基准的漂移强度；
5. 可选的最近 1–6 个已知/自预测截面的状态变化，不包含未来截面。

所有连续统计先做 Train-only robust scaling，再用 Train-only PCA 压到 16–32 维。距离默认使用收缩协方差下的 Mahalanobis 距离，并以余弦距离作消融。

候选近邻必须满足 `s<t`。在每个 OOF fold 中，检索库严格截止到该 fold 的训练终点。比较三种采样：

- 相似状态 top-K：主方法；
- 最近 K 个历史截面：时间近邻对照；
- 随机 K 个历史截面：负对照。

## 6. 实验序列

### exp024a：只读检索诊断

唯一变量：历史截面的选择方式。

不训练新预测模型、不生成提交文件。使用已有三折 OOF 与 official Valid，验证：

- 状态距离能否预测 exp021 的截面 IC 和残差结构；
- 相似状态近邻是否优于最近窗口和随机近邻；
- 检索置信度是否与候选相对 exp021 的收益单调相关；
- 高漂移截面是否能找到更合适的历史状态，而不是简单丢弃。

通过条件：

- 三个 expanding folds 中，相似状态检索均优于随机对照；
- 至少两个 fold 优于最近窗口；
- 置信度分位数与收益存在稳定单调关系；
- 所有结论在去掉任一单个时间块后不反转。

### exp024b：检索加权 Rank 残差模型

基线：冻结 exp021；exp023h 的锚点部分不参与训练选择。

目标定义：

```text
r(s, stock) = rank(y_s) - rank(exp021_s)
```

只训练一个轻量残差模型。首选 LightGBM 回归/排序模型，输入保持精简：稳定特征的截面 rank、六家族 OOF rank、家族分歧和少量状态交互。训练行来自检索到的历史截面，并按状态距离加权。

对照模型使用完全相同的特征、参数和样本数，仅把检索权重替换为最近窗口或均匀权重。这样唯一被验证的变量仍然是“状态检索”。

输出先转为组内 rank，再以很小的 `alpha` 校正 exp021：

```text
candidate_rank = rank(exp021) + alpha * normalized_residual_rank
```

`alpha` 只能通过嵌套 walk-forward 选择，不得直接在 official Valid 网格搜索后汇报同段结果。

### exp024c：高置信截面手术

唯一变量：是否启用截面级 gate。

gate 不读取标签，只读取检索距离、邻居间一致性、残差模型种子方差、专家分歧、漂移程度。gate 的阈值只在早期 OOF fold 拟合，在后续 fold 验证。

最终 Test 规则：

```text
if t < 6:
    prediction = exp023h
elif gate(z_t) == pass:
    prediction = shrink(exp023h, residual_candidate, alpha_t)
else:
    prediction = exp023h  # 逐值保持
```

目标修改比例为剩余截面的 10%–25%；若 gate 选择超过 30%，视为失去“局部手术”约束，不进入线上候选。

### exp024d：可微 Spearman 消融

仅当 exp024b/c 已经通过时执行。保持数据、模型输入、gate 和参数预算不变，只把残差校准器的相关性目标替换为 soft-rank Spearman。

比较：

- 当前 Pearson + pairwise 目标；
- soft Spearman；
- `0.7 × soft Spearman + 0.3 × pairwise`。

若需要新增依赖，必须先固定版本并做数值/梯度 smoke test；依赖失败时不自制未经验证的大型排序算子，直接保留 exp024c。

## 7. 验收与停止条件

所有候选必须同时满足：

- safety contract、prediction contract、项目审计全部通过；
- 三折 expanding walk-forward 的增益均为正；
- official Valid 全量 mean IC 相对 exp021 至少 `+0.0025`；
- 被 gate 选中的截面平均 delta 为正，且 block bootstrap 的 90% 下界大于 0；
- 最差 10% 截面均值不下降超过 `0.001`；
- 后半段和高漂移子集均不为负增益；
- 三个随机种子的 full-valid delta 标准差不超过 `0.0005`；
- 不修改 exp021、exp023h、final_submission 的文件与哈希；
- 生成独立 prediction、metrics、metadata、per-time delta 和 SHA-256。

`+0.0025` 门槛高于项目既有的 `+0.002` 普通栈改动门槛，并给本地到线上迁移衰减留出余量。任何核心条件失败就停止该路线，不用线上提交试错。

## 8. 线上提交策略

已知额度：平台每日最多提交 3 次；`2026-08-23` 尚余 3 次。额度是上限，不是当日必须消耗的次数。

1. 只提交通过全部门槛、且预注册参数已经冻结的 exp024 候选；
2. 第一份线上候选只验证 SRRRS 主机制；
3. 第二份只有在 soft Spearman 对多个后置 fold 都形成独立增益时才提交；
4. 不在线上试 K、alpha、gate 阈值或特征组合；
5. 线上结果无论正负都写入 `_decision_log/`，不覆盖 exp023h 或 formal_submission；
6. 只有线上 `>0.12` 且用户明确授权时，才讨论晋级正式提交。

## 9. 预计执行顺序与产物

1. 预注册 exp024a，生成状态缓存、检索诊断和负对照报告；

每一阶段至少生成：

## 13. exp026a 实际结果（2026-08-23）

最后检查了一个与 exp023a 强机制直接相关、但信息边界合法的新假设：只用 `X(<=t)` 预测 exp023a 的未来变化特征，再把预测代理用于当前排序。

- `num_348@+5` 等未来特征确实存在一定可预测性，未来特征 RankIC 最高达到 `0.372240`；
- 但 forecast 代理融入 exp021 后为 `-0.000592`；
- 同掩码 persistence 代理为 `-0.000824`，forecast 只领先 `+0.000232`；
- 三个时间段中两个为负；
- 保护哈希不变，无 Test 输入、预测文件或线上提交。

解释：未来真实特征中与 y(t) 高度相关的是新的、尚未发生的变化；历史可预测部分主要是平滑/持久成分，并没有贡献额外的截面排序信息。因此停止 exp026，不升级 Ridge、不增加深层 forecaster。

截至本轮结束，三个相互独立的新假设——状态检索、直接 Spearman、合规未来特征代理——均在提交前被严格诊断否决。当前证据支持保留 exp023h `0.119660`，今日 `3/3` 次线上额度全部保留。
