## 3. 数据处理

- 特征视图：`legacy_328`（processed_data_v1 tree 视图前 328 列），与 exp_003/exp_009 完全一致，缓存兼容校验通过（最大绝对误差 < 1e-7）。
- 缺失处理：使用缓存中已按因果方式处理的特征（趋势填充仅在训练区间内拟合），本次直接复用缓存，未重新生成数十 GB 特征。
- 滞后与滚动特征的因果性：lag_1/5/20/60、roll_mean/std/change 5/20/60、历史覆盖率、存续时间全部只使用当前时点及以前信息。
- 样本抽取方式：每个时间点确定性（linspace 均匀抽取）至多 1200 只股票。
- 标签 64 档转换：`min(floor(clip(y,0,1)*64), 63)`，与缓存 `train_relevance.npy` 一致。
- 是否加入 Valid 重训：**否**（重训模拟未通过，见第 6 节）。最终模型为 Train-only。

## 5. 验证结果

- 开发折（fold_1 [2189,2432)、fold_2 [2432,2675)）：锚点 0.112031 / 0.097117；权重 0.25/0.30/0.35 的平均增量 0.000938 / 0.001022 / 0.001066，选定最低达到 95% 阈值的权重 **0.30**。
- 影子验证 [2675,2918)（单种子 42）：锚点 0.083772 → 融合 0.085259，增量 **+0.001487**。
- 官方 Valid [2918,3161)（单种子 42）：锚点 0.092940 → 融合 0.093634，增量 **+0.000694**；前半 0.095641（锚点 0.094021）、后半 0.091643（锚点 0.091868）、最差季度 0.060182（锚点 0.059262）。
- 相对锚点增量：官方 Valid +0.000694、影子验证 +0.001487、开发折平均 +0.001022。

## 6. 重训模拟（是否加入 Valid 重训）

- 模拟一（旧训练至 2189，新训练至 2432，预测 [2432,2675)）：融合 RankIC 0.100256 → 0.098089，增量 **-0.002168**（前半 -0.002894、后半 -0.001448、最差季度 -0.001373）。
- 模拟二（旧训练至 2432，新训练至 2675，预测 [2675,2918)）：融合 RankIC 0.077229 → 0.085259，增量 **+0.008030**（前半 +0.011579、后半 +0.004510、最差季度 +0.005892）。
- 两个模拟平均增量为正（+0.002931），但模拟一出现严重负向回撤，**判定不通过**。
- 结论：加入最近一段标签不能稳定改善下一段预测，最终**不使用 Train+Valid 重训**。

## 11. 风险与限制

- 本地 Valid 与线上可能存在分布差异，线上成绩无法由本地完全推断。
- 官方 Valid 样本较短（243 个时间点），增量可能受噪声影响。
- 特征匿名导致经济含义不可解释，无法进行基本面校验。
- Train 内部增益不一定迁移到官方 Valid 与线上（本实验消融、重训模拟均验证了这一点）。
- 多种子间方差显著，单种子结果对随机种子敏感，正式提交前建议进行更多种子稳定性测试。
- 小权重 TCN/线性融合在官方 Valid 上有正增量，但缺乏开发折/影子验证分量验证，未纳入候选。
